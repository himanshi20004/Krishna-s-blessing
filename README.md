# 🪕 Krishna's Blessing: Bhagavad Gita AI Chatbot

A specialized conversational AI platform designed to offer timeless wisdom and philosophical guidance. By aligning the chatbot's context with the sacred verses of the Bhagavad Gita, users can seek clarity on modern life dilemmas, stress, duty (Dharma), and self-realization through spiritual dialogue.

## ✨ Features
- **📜 Scriptural Context Alignment:** Programmed to synthesize answers directly reflecting the core philosophies and shlokas of the Bhagavad Gita.
- **🙏 Empathetic Spiritual Guidance:** Tailored conversational style providing calm, practical, and philosophical remedies to personal and emotional conflicts.
- **⚡ Seamless Server Integration:** Powered by a clean backend setup (`server.js`) to handle messaging pipelines and secure requests efficiently.
- **🌐 Live Web Interface:** Fully structured web application designed for interactive user accessibility.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3, JavaScript
- **AI Engine:** Customized LLM Prompting & API Integration
- **Deployment:** Vercel (`krishna-s-blessing.vercel.app`)
